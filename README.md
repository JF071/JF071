## 💫 Sobre mí

Soy Ingeniero de Software apasionado por el desarrollo de soluciones tecnológicas que optimicen procesos empresariales y generen impacto real. Me especializo en **desarrollo full stack**, **automatización**, **integración de sistemas ERP/POS** y construcción de aplicaciones web modernas.

Durante mi experiencia profesional he trabajado en proyectos relacionados con:

- 📊 **Análisis de datos** con Python y visualización
- 🏪 **Integración ERP/POS** — desarrollo de plataformas empresariales conectadas

Me considero una persona analítica, autodidacta y orientada a resultados, con facilidad para adaptarme a nuevas tecnologías y asumir retos técnicos.
