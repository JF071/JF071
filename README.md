# 💫 Sobre mi:
Soy Ingeniero de Software apasionado por el desarrollo de soluciones tecnológicas que optimicen procesos empresariales y generen impacto real. Me especializo en desarrollo full stack, automatización, integración de sistemas ERP/POS y construcción de aplicaciones web modernas.<br><br>Durante mi experiencia profesional he trabajado en proyectos relacionados con facturación electrónica, análisis de datos, sincronización de bases de datos, automatización de procesos y desarrollo de plataformas empresariales utilizando tecnologías como Python, Next.js, TypeScript, React, Django, C#, SQL Server y PostgreSQL.<br><br>Me considero una persona analítica, autodidacta y orientada a resultados, con facilidad para adaptarme a nuevas tecnologías y asumir retos técnicos. Disfruto aprender constantemente, crear soluciones escalables y aportar valor a través de la tecnología y la innovación.<br>
